先說重點

  • 不需註冊帳號，也不要求姓名、電話、Apple ID 或付款資訊。
  • 只有你主動開始辨識時，壓縮後的菜單照片才會經 Cloudflare 傳送至 Google Gemini。
  • 我們目前不使用廣告 SDK、跨 App 追蹤或行銷分析工具，也不出售或出租資料。
  • 辨識歷史與壓縮照片留在 iPhone 的 App 私有空間，供當天重看；可手動刪除，跨日也會由 App 清除。

飯譯 OrderLingo（以下稱「本 App」）由飯譯 OrderLingo 開發團隊（以下稱「我們」）提供。本政策說明你使用本 App 時，哪些資料會留在 iPhone、哪些資料會傳送至雲端，以及你可以如何管理資料。

2. 我們處理的資料

2.1 菜單照片與辨識內容

當你主動開始辨識時，本 App 會處理你選擇或拍攝的菜單照片。照片會先在 iPhone 上縮小與壓縮，再傳送至我們的 Cloudflare Worker，並由 Worker 轉送至 Google Gemini API。傳送內容可能包括：

  • 壓縮後的菜單照片；
  • 你選擇的來源語言提示與目標翻譯語言；
  • 為執行辨識而加入的系統提示文字；
  • Gemini 產生的菜名、翻譯、價格、位置與其他辨識結果。

用途僅限於完成你要求的菜單辨識與翻譯。我們的 Worker 應用程式目前不會主動將菜單照片寫入 Cloudflare KV 或其他資料庫；不過 Cloudflare 與 Google 仍可能依其服務條款、安全與營運政策處理網路請求與日誌。

請勿上傳敏感內容。 請避免照片含有人臉、姓名、聯絡方式、付款資訊、身分證件、醫療資訊或其他與菜單辨識無關的內容。如果照片中包含第三人的資料，請先確保你有權提供。

2.2 菜品資訊查詢

當你點選菜品的「AI 資訊」功能時，本 App 會傳送菜名、來源語言、目標語言，以及可能用於辨識同名菜色的菜單文字情境。Gemini 會產生一般性的食材、口味、烹調方式、常見過敏原、辣度、素食判斷與文化背景。

為減少重複的 AI 請求，本 App 可能在 iPhone 的本機偏好設定中快取菜品說明；Worker 也可能在 Cloudflare KV 快取以菜名與語言組合產生的通用菜品說明。伺服器端通用菜品快取不會附帶你的匿名裝置識別碼。

AI 內容可能有誤。 尤其是食材、過敏原與素食判斷，請以餐廳或食品業者提供的資訊為準，不應把 AI 回答作為醫療或飲食安全的唯一依據。

2.3 匿名裝置識別碼與每日配額

本 App 會隨機產生一組裝置識別碼，保存在 App 的本機偏好設定中。它不是 Apple 的廣告識別碼，也不包含姓名、電話、電子郵件、Apple ID 或裝置序號。

每次使用雲端功能時，識別碼會透過 X-Device-Id 請求標頭傳送至 Worker。Worker 會在 Cloudflare KV 以「匿名識別碼＋UTC 日期」記錄當日使用次數，用來顯示及限制免費額度。這些紀錄不會被用於廣告、跨服務追蹤或建立使用者輪廓。

2.4 網路與技術資料

連線至雲端服務時，Cloudflare、Google 及其基礎設施可能自動處理 IP 位址、請求時間、HTTP 標頭、裝置或網路技術資訊、安全過濾結果、錯誤資訊與用量指標。這些資料可能用於傳輸請求、防止濫用、維持服務、安全監控、計費或符合法律義務。

我們目前沒有在 App 中整合廣告、第三方行銷分析或跨 App 追蹤 SDK。

2.5 本機辨識歷史

辨識完成後，壓縮後的照片、辨識結果、來源語言、目標語言與建立時間會保存在這台 iPhone 的 App 私有 Application Support 目錄，且該目錄會排除於 iCloud 備份。

  • 歷史紀錄僅供你在當天重看；
  • App 在首頁或歷史頁啟動清理時，會刪除早於當天的紀錄；
  • 你可以在歷史紀錄中向左滑動，立即刪除個別紀錄；
  • 刪除本 App 會一併移除 App 的本機資料。

3. 第三方服務

Cloudflare

我們使用 Cloudflare Workers 傳遞 API 請求，並使用 Cloudflare KV 保存每日配額計數與通用菜品說明快取。Cloudflare 可能以服務供應商身分處理網路與技術資料。詳見 Cloudflare 隱私權政策 ↗。

Google Gemini API

我們使用 Google Gemini API 處理菜單圖片、辨識提示、翻譯與菜品資訊。Google 對資料的使用方式取決於本服務所使用的 Gemini API 方案及當時適用的條款：

  • 依 Google 現行政策，為偵測與防止濫用，提示、情境資訊與模型輸出可能保留 55 天；被安全系統標記的內容可能由 Google 授權人員檢視。
  • 使用未付費 Gemini API 服務時，Google 可能使用提交內容與回覆來提供、改善及開發其產品與機器學習技術，並可能由人工審查人員處理。
  • 使用已啟用 Cloud Billing 的付費服務時，Google 表示不會使用提示、檔案或回覆來改善其產品，但仍會為安全、防止濫用與法令要求在有限期間內記錄資料。

請參閱 Gemini API 附加服務條款 ↗、Gemini API 濫用監控說明 ↗及 Google 隱私權政策 ↗。第三方條款可能由供應商更新；如其處理方式有重大變更，我們會評估並更新本政策與服務設定。

5. 你的選擇與權利

你可以：

  • 在首次雲端辨識告知畫面選擇「暫不使用」；不同意時，雲端辨識功能不會啟用。
  • 不選擇或不拍攝照片，避免傳送任何菜單圖片。
  • 在歷史紀錄中刪除個別本機紀錄。
  • 停止使用雲端辨識，或刪除本 App 以移除本機資料並撤回後續處理的同意。
  • 依適用法律請求查詢或閱覽、取得複製本、補充或更正、停止蒐集／處理／利用，或刪除我們可識別並控制的個人資料。

若要提出資料權利或刪除請求，請寄信至 icimcse100@gmail.com，主旨註明「飯譯 OrderLingo 隱私請求」，並說明你的請求內容。我們可能需要合理資訊來驗證請求並避免誤刪他人資料。

本 App 不提供帳號，伺服器端配額紀錄僅使用隨機識別碼。因此，如果現有資訊無法合理對應到特定紀錄，我們可能無法僅憑姓名或電子郵件定位該匿名紀錄；遇到這種情況，我們會說明可行的處理方式。第三方供應商所控制的資料也可能需要依其隱私權政策直接提出請求。

6. 不提供資料的影響

你可以自由選擇是否提供菜單照片與使用雲端功能。不提供照片或不同意雲端處理時，你仍可閱讀本政策，但無法使用需要遠端模型的菜單辨識、翻譯及 AI 菜品資訊功能。

7. 資料安全

我們採取與服務規模相稱的合理措施，例如使用 HTTPS 傳輸、縮小傳送圖片、將 API 金鑰保存在伺服器端、限制 Worker 接收的必要欄位，以及把本機歷史放在 App 私有空間。然而，任何網路傳輸或儲存方式都無法保證百分之百安全。

8. 國際傳輸

Cloudflare、Google 或其受託服務商可能在台灣以外的國家或地區處理、暫存或快取資料。這些地區的資料保護法律可能與你所在地不同。你同意使用雲端功能時，即表示你了解完成服務所必要的跨境處理；我們會選用具公開隱私與安全承諾的服務供應商，並依適用法律處理。

9. 未成年人

本 App 的雲端 AI 功能不以未滿 18 歲者為對象。未滿 18 歲者不應使用雲端辨識或提交任何內容。若你認為未成年人已透過本 App 提交個人資料，請聯絡我們；在可合理定位且法律要求的範圍內，我們會採取刪除或其他適當措施。

10. 政策變更

當功能、資料處理方式、服務供應商或法令要求發生變更時，我們可能更新本政策。更新後會調整頁首的「最近更新」日期；如變更會重大影響你的權益，我們會在 App 內以適當方式重新告知或取得同意。
